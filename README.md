## Безпека та захист даних

* **Захист від XSS:** Вставки через `innerHTML` чи `v-html` у проєкті відсутні. Рендеринг користувацьких нотаток (`note`) та даних із API реалізовано через текстову інтерполяцію Vue 3 (`{{ note }}`), що забезпечує автоматичне HTML-екранування.

* **Локальні сховища (`localStorage` / `IndexedDB`):** Записи користувача зберігаються в `IndexedDB` (`MoodTrackerDB`). Після міграції даних із `localStorage` старий ключ `moodEntries` видаляється для уникнення дублювання.

* **Секрети та HTTPS:** Захардкоджені ключі чи паролі в коді відсутні. Розгортання застосунку на **Vercel** забезпечує захищене з'єднання за протоколом HTTPS за замовчуванням.
